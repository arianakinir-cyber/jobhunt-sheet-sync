# Privacy policy — Job-hunt sheet sync

Last updated: 2026-10-15

**Who uses it.** This is a personal tool, run by its owner for their own use. It has no public users.

**What it accesses.** With the owner's consent, it reads and edits the one Google Sheet the owner configures, through
the Google Sheets API (scope `https://www.googleapis.com/auth/spreadsheets`). It does not access Gmail, Google Drive
files other than that spreadsheet, contacts, or any other Google data.

**What it stores.** The OAuth token is stored only on the owner's own computer. Job postings it collects come from
public job boards and are kept in the owner's own spreadsheet and on the owner's computer.

**Sharing.** No data obtained through Google APIs is sold, shared with third parties, used for advertising, or used to
train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy,
including the Limited Use requirements.

**Removal.** The owner can revoke access at any time at https://myaccount.google.com/permissions; deleting the local
token file ends all access.

**Contact.** Through the support email shown on the app's Google consent screen.
